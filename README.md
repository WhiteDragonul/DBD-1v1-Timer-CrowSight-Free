# CrowSight Free - DBD Overlay with a 1v1 Timer

The free version of **CrowSight**, a Dead by Daylight overlay for Windows 10 and 11.
It puts a **DBD 1v1 timer**, perk timers and a custom crosshair on top of your game,
with no account needed.

**Download:** https://www.crowsightoverlay.com/download

## What's included

- **1v1 Timer** - chase timers for both players with the score on screen, for 1v1s and tournaments
- **Perk timers** - Endurance and Elusive, counted down live in the overlay
- **Custom crosshair** - a center-screen crosshair overlay for ranged killers

## Safe to use

CrowSight reads no game memory and injects no code into Dead by Daylight. It runs
outside the game process, the same way OBS or Discord overlays do.
